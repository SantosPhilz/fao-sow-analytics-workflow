# FAO SoW Analytics Workflow

## Overview
This repository presents a **public-safe portfolio version** of analytical work related to questionnaire processing, figure and table preparation, regional summaries, map-ready outputs, and technical reporting workflows in animal genetic resources and livestock systems.

It is designed to show:
- data cleaning and restructuring logic,
- regional and global comparison workflows,
- figure and table generation pipelines,
- mapping and output preparation in R,
- and the ability to turn raw reporting inputs into structured analytical outputs.

## Important note on confidentiality
This repository **does not include confidential FAO data, unpublished source datasets, or restricted visuals**.

The scripts are shared as a portfolio demonstration of workflow and analytical structure.  
If needed, datasets can be replaced with:
- anonymized sample data,
- simulated data with the same column structure,
- or a data dictionary and reproducibility notes.

## Repository structure
- `scripts/` – R scripts prepared from your uploaded workflow files
- `data/` – placeholder for public-safe sample or anonymized data only
- `outputs/` – placeholder for approved charts, maps, tables, or screenshots
- `docs/` – notes explaining context and safe sharing rules

## Scripts currently included
1. `01_maps_figures_workflow.R`  
   Mapping and figure-related workflow for selected outputs.

2. `02_table_3E1_2_workflow.R`  
   Row-level counts and percentage workflow for technology tables.

3. `03_figures_tables_collection.R`  
   Larger figure and table generation script collection for analytical outputs.
